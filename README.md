# TESS QPP

Independent research project on short-period quasi-periodic pulsations (QPP) in TESS stellar flares.

## Scope

The project investigates the robustness, selection effects, validation properties, population implications, and physical interpretation of short-period QPP analysis in TESS flare data.

The repository is designed as a long-lived project workspace rather than as the repository of a single manuscript.

## Repository model

- `foundation/` — historical and frozen foundations from completed phases.
- `docs/` — project governance, decisions, and scientific roadmap.
- `workflows/` — phase-specific active analysis workflows.
- `src/` — reusable project code shared across phases.
- `tests/` — reusable software and scientific validation tests.
- `data/` — documentation and references for data that are not committed directly to Git.
- `manuscripts/` — manuscript-specific material derived from validated project evidence.

Complete frozen scientific snapshots are maintained outside the Git working history through the project's research-archive infrastructure.

## Current status

Phases F0–F2 form the frozen methodological and observational foundation of the project.

Development continues with Phase 3A and Phase 3B.
