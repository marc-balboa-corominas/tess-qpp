# Project Roadmap

## Frozen foundation

### Phase 0

Reconstruction, audit, and validation of the effective baseline procedure.

Status: complete.

### Phase 1

Synthetic methodological benchmarks, numerical diagnostics, and nested-window support analysis.

Status: complete.

### Phase 2

Pilot observational robustness analysis and documentary synthesis.

Status: complete.

## Current development

### Phase 3A

Catalogue-scale observational robustness analysis.

### Phase 3B

Realistic injection-recovery analysis and independent held-out validation.

## Manuscript 1

The first principal manuscript is expected to integrate the robustness and validation evidence developed through Phase 3A and Phase 3B.

## Later development

Subsequent phases will address population-level correction, physical relations, and final sensitivity analyses.

## Manuscript 2

A second manuscript is reserved for the broader population and physical-inference stage of the research program.

## Principle

The project repository represents the complete research program and must not be structurally coupled to a single phase or manuscript.
